# 御霊前名札作成システム（ラベルマイティ17 代替テンプレート）

ジャストシステム「ラベルマイティ17」の製造中止に伴い、供花（お花）に付ける「御霊前」名札のうち、
送り主の氏名部分をExcel（`御霊前名札作成システム.xlsx`）から印刷するためのテンプレートです。

「御霊前」の文字や菊柄・金枠などは、あらかじめ印刷済みの専用台紙（既製品）を使用する前提です。
Excel側では氏名だけを、台紙の白紙部分に正しい位置で印刷します。

## 台紙のサイズ

| 名札 | 台紙全体 | 白紙印刷部分 | 状態 |
| --- | --- | --- | --- |
| 小さい名札 | 縦493mm×横200mm | 縦345mm×横170mm | 実測値（確定） |
| 大きい名札 | 縦540mm×横192mm | 縦378mm×横163mm | ★推定値（未実測・要確認） |

大きい名札の白紙部分サイズは、小さい名札と同じ比率で仮計算した推定値です。実際の台紙で
白紙部分の縦横mmを実測いただき次第、正確な値に更新します。**それまでは大きい名札シートでの
本番印刷は控えてください。**

白紙部分はどちらの台紙も「上部に台紙の柄、下部が白紙」の配置（下揃え・左右中央）という前提で
作成しています。

## ファイル構成

- `御霊前名札作成システム.xlsx` — 本体ファイル
  - `使い方` シート：操作手順・印刷方法・注意事項
  - `設定` シート：台紙サイズ・白紙部分サイズの一覧（実測値／推定値の管理）
  - `御霊前名札（小）` シート：縦493mm×横200mm 台紙用
  - `御霊前名札（大）` シート：縦540mm×横192mm 台紙用（★白紙部分サイズ未確定）

## 使い方（概要）

1. `御霊前名札（小）` または `御霊前名札（大）` シートを開く。
2. オレンジ色のマスに、氏名を1マスに1文字ずつ、上から順番に入力する（縦書きのイメージ）。
   姓と名の間を少し空けたい場合は、その1マスを空欄のままにする。使わない下側のマスも空欄でよい。
3. 文字サイズは初期値（110pt）のまま印刷し、名前の長さに応じてホーム→フォントサイズで調整する。

## 印刷方法（重要）

1. プリンタードライバーの「ユーザー定義用紙サイズ」で、台紙の全体サイズ（縦×横）を登録する。
2. 印刷ダイアログでその用紙サイズを選択し、実際の台紙（専用紙）をセットして印刷する。
3. 各名札シートは印刷倍率が「1ページに収める（横1×縦1）」に設定済みのため、登録した用紙サイズ
   いっぱいに自動的に拡大縮小されます。**まずは普通紙で試し印刷し、実際の台紙に重ねて位置を
   確認してから**ご使用ください。
4. 位置が少しずれる場合は、シート上部の余白行の高さ／左右の余白列の幅をExcelの行の高さ・列の幅の
   設定から微調整してください（各シートの余白部分にコメントで目安の高さ・幅を記載しています）。

詳細はブック内の `使い方` シートを参照してください。
