# 名札作成システム（ラベルマイティ17 代替テンプレート）

ジャストシステム「ラベルマイティ17」の製造中止に伴い、名札印刷業務を Excel（`名札作成システム.xlsx`）で
代替するためのテンプレートです。

## 用途

顧客要望に基づき、以下2サイズの名札テンプレートを収録しています。

| テンプレート | 縦 | 横 |
| --- | --- | --- |
| 大きい名札 | 540mm | 192mm |
| 小さい名札 | 493mm | 200mm |

## ファイル構成

- `名札作成システム.xlsx` — 本体ファイル
  - `使い方` シート：操作手順・用紙サイズに関する注意事項
  - `名簿` シート：印刷対象者の一覧（No. / 氏名 / ふりがな / 所属・クラス / 備考）を入力
  - `大きい名札` シート：縦540mm×横192mm の名札デザイン。黄色いセルに名簿番号を入力すると
    氏名・ふりがな・所属が自動反映される
  - `小さい名札` シート：縦493mm×横200mm の名札デザイン。同上

## 使い方（概要）

1. `名簿` シートに氏名・ふりがな・所属（クラス／部署）などを入力する。
2. `大きい名札` または `小さい名札` シートを開き、黄色いセル（No. 欄）に印刷したい人の名簿番号を入力する。
3. 名前などが自動的に反映されるので内容を確認して印刷する（1名分＝1ページ）。
4. 名簿番号を変えて 1〜3 を繰り返すことで、複数名分の名札を順番に印刷できる。

詳細な注意点（用紙サイズの登録方法など）はブック内の `使い方` シートを参照してください。

## 用紙サイズについての注意

540mm×192mm、493mm×200mm はいずれも汎用のA判・B判に存在しないサイズです。
印刷時はお使いのプリンタードライバーの「ユーザー定義用紙サイズ」機能で縦横寸法を登録してください。
各名札シートはあらかじめ印刷倍率を「1ページに収める（横1×縦1）」に設定しているため、登録した
用紙サイズいっぱいにデザインが自動的に拡大縮小されます。対応する大判プリンター・カット紙／ロール紙を
ご用意のうえ、試し印刷で実寸を確認してからご使用ください。
